# Small Restaurant Database Project

This database is designed for one small restaurant and focuses on the daily operations described in the project proposal. The design includes Customers, Employees, Employee_Shifts, Restaurant_Tables, Reservations, Menu_Items, Orders, Order_Items, Discounts, Order_Discounts, Gift_Cards, and Payments. Employee_Shifts was added because managers need employee schedules, while Restaurant_Tables supports reservations and table numbers. Orders and Order_Items track sales, menu items, special instructions, status, taxes, discounts, and receipts. Payments supports cash, cards, gift cards, tips, and split payments. Gift_Cards is separate so remaining balances can be tracked correctly. The sample data is intentionally sized for a small business: 11 active employees, 12 restaurant tables, 32 menu items, and 40 sample orders. Vendors, inventory, payroll accounting, and other bookkeeping functions are outside the current project scope.
